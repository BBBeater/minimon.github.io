# 🍮 มอนสเตอร์ขนมหวาน

เกมการ์ดสุ่มสะสมมอนสเตอร์น่ารัก สำหรับ 2 ผู้เล่น เล่นบนเว็บ (HTML + CSS + JavaScript ไฟล์เดียว ไม่ต้องติดตั้งอะไร)

- 8 ธาตุ (🔥💧🌿⚡⛰️❄️💨🌑) แพ้ชนะกันแบบสมดุล: ทุกธาตุชนะ 3 · แพ้ 3 · เสมอ 1
- การ์ด 100 ใบ (ธรรมดา 52 · หายาก 32 · ตำนาน 16) บางใบมีความสามารถพิเศษ
- เหรียญ 🪙 → เปิดซอง 10 ใบ → จัดเด็ค 10 ใบ (งบเด็ค 18, ซ้ำได้ไม่เกิน 3 ใบ)
- เล่นกับบอท หรือเล่นกับเพื่อนคนละเครื่อง (ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องล็อกอิน)

## วิธีเล่นแบบย่อ

1. ทุกรอบเลือกการ์ด 1 ใบจากมือ (เริ่ม 5 ใบ) แล้วกด "ลงการ์ด" เปิดพร้อมกัน
2. พลังรวม = พลังการ์ด + โบนัสธาตุ (+2 ถ้าชนะทางธาตุ) ฝ่ายสูงกว่าได้ 1 แต้ม
3. ผู้ชนะรอบจั่วการ์ดจากเด็คเพิ่ม 1 ใบ
4. ใครได้ 3 แต้มก่อนชนะ (ครบ 5 รอบ ดูแต้มมากกว่า)
5. ชนะ +40🪙 · เสมอ +25🪙 · แพ้ +15🪙 ไปเปิดซองเพิ่มได้ (ซองละ 100🪙)

ในเกมมีปุ่ม 📖 อธิบายตารางธาตุและความสามารถให้กดอ่านระหว่างสู้

## เอาขึ้น GitHub Pages (ฟรี)

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมด (หรือใช้คำสั่งด้านล่าง)
2. ไปที่ **Settings → Pages**
3. ที่ **Build and deployment** เลือก **Source: Deploy from a branch**, Branch: `main`, โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` ส่งให้เพื่อนได้เลย

```bash
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ repo>.git
git push -u origin main
```

## ลองเล่นในเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์ชั่วคราว:

```bash
python3 -m http.server 8000   # แล้วเปิด http://localhost:8000
```

## เล่นกับเพื่อนยังไง

ใช้ WebRTC เชื่อมต่อตรงระหว่างสองเครื่อง โดยแลก "โค้ด" กันทางแชต 2 ครั้ง (ไม่มีเซิร์ฟเวอร์กลาง)

1. เจ้าของห้องกด **สร้างห้อง** แล้วส่งโค้ดให้เพื่อน
2. เพื่อนกด **ฉันเป็นเพื่อน** วางโค้ด กด **สร้างโค้ดตอบกลับ** แล้วส่งกลับ
3. เจ้าของห้องวางโค้ดตอบกลับ กด **เชื่อมต่อ**

ข้อจำกัด: บางเครือข่าย (wifi บริษัท / เน็ตมือถือบางเจ้า) อาจเชื่อมตรงไม่ได้เพราะไม่มี TURN server ถ้าเชื่อมไม่ติดให้ลองสลับเครือข่าย
โค้ดห้องอาจใช้เวลาสร้างหลายวินาที เพราะรอรวบรวมที่อยู่เครือข่ายจาก STUN server (ปรับเวลารอได้ที่ฟังก์ชัน `gathered` ใน `index.html`)

## ปรับแต่งเกม

ทุกอย่างอยู่ใน `<script>` ของ `index.html`:

| อยากแก้อะไร | ดูที่ตัวแปร |
|---|---|
| รายชื่อ/อีโมจิ/พลัง/ความสามารถของการ์ด | `D`, `PC`, `PR`, `PL` |
| ธาตุแพ้ชนะ | `BEAT` (และคำอธิบายใน `WHY`) |
| ความสามารถการ์ด | `AB` และฟังก์ชัน `duel` |
| ราคาซอง / งบเด็ค / จำนวนการ์ดซ้ำ | `PACK`, `BUD`, `CST`, `MAXC` |
| โอกาสสุ่มความหายาก | ฟังก์ชัน `one` |

## ข้อมูลผู้เล่น

เหรียญ การ์ดที่สะสม และเด็คเก็บใน `localStorage` ของเบราว์เซอร์ (คีย์ `mc2`) ล้างข้อมูลเบราว์เซอร์แล้วจะหาย
ระบบสุ่มและการตัดสินทำที่ฝั่งผู้เล่น เหมาะกับเล่นกับเพื่อน ไม่เหมาะกับแข่งจริงจัง
